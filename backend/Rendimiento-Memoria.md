# Solución recomendada

Vamos a aumentar el archivo de paginación de Windows.

Presioná:
Windows + R
Escribí:
   
    sysdm.cpl
    
Enter.
Pestaña Opciones avanzadas.
En Rendimiento, hacé clic en:

Configuración

Otra vez pestaña:

Opciones avanzadas

En Memoria virtual, hacé clic en:

Cambiar...

Desmarcá:

Administrar automáticamente el tamaño del archivo de paginación para todas las unidades

Seleccioná tu unidad C:.
Elegí:

Tamaño personalizado

Podemos poner, por ejemplo:

Tamaño inicial: 4096 MB
Tamaño máximo: 8192 MB
Establecer → Aceptar.
Windows probablemente te va a pedir reiniciar.
